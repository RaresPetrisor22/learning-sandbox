# TypeScript Pizza Shop

**Source:** https://www.youtube.com/watch?v=SpwzRDUQ1GI

A 2-hour intro to TypeScript basics. What I've learnt:

- Benefits of using TypeScript over regular JS
- Basic, literal and custom types
- Optional properties
- Unions
- Type Narrowing
- Utility Types
- Generics

### How to Run

Run `node index.ts` in terminal
